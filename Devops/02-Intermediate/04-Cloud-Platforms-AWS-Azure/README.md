# Cloud Platforms - AWS & Azure

## Overview
Learn cloud fundamentals and deploy applications on AWS and Azure.

## Topics
- Cloud computing concepts (IaaS, PaaS, SaaS)
- AWS: EC2, S3, RDS, Lambda, ECS
- Azure: VMs, Blob Storage, App Service, Functions
- Networking and security groups
- Load balancers and auto-scaling
- Identity and access management

## Hands-On Tasks
1. Create cloud accounts (free tier)
2. Deploy VM instances
3. Set up object storage
4. Deploy containerized app
5. Configure load balancer
