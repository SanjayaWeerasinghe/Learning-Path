# DevOps Learning Path

Welcome to your comprehensive DevOps journey! This curriculum will take you from Linux fundamentals to advanced Kubernetes and cloud deployments.

## 🎯 Learning Roadmap

```
Linux & Git (Basics)
    ↓
Docker & CI/CD (Basics)
    ↓
Kubernetes & Cloud (Intermediate)
    ↓
Production DevOps (Advanced)
    ↓
DevOps Engineer! 🚀
```

## 📚 Course Structure

### 01-Basics (5-8 weeks)
Foundation skills every DevOps engineer must have.

**01-Linux-Fundamentals** (1 week)
- File system navigation
- Essential commands
- Process management
- Text processing

**02-Git-Version-Control** (1 week)
- Git workflow
- Branching and merging
- Collaboration patterns
- Best practices

**03-Docker-Basics** (1-2 weeks)
- Container concepts
- Dockerfile creation
- Image management
- Container networking

**04-CI-CD-Introduction** (1-2 weeks)
- Pipeline concepts
- GitHub Actions
- Automated testing
- Deployment automation

**05-Shell-Scripting** (1 week)
- Bash scripting
- Automation scripts
- System administration
- Error handling

### 02-Intermediate (8-10 weeks)
Production-ready skills for real-world deployments.

**01-Docker-Compose** (1 week)
- Multi-container apps
- Service orchestration
- Environment management
- Development workflows

**02-Kubernetes-Basics** (2 weeks)
- K8s architecture
- Pods and Deployments
- Services and networking
- ConfigMaps and Secrets

**03-Jenkins-GitHub-Actions** (2 weeks)
- Jenkins pipelines
- Advanced workflows
- Security scanning
- Deployment strategies

**04-Cloud-Platforms-AWS-Azure** (2 weeks)
- Cloud fundamentals
- Compute and storage
- Networking
- Managed services

**05-Infrastructure-as-Code** (2 weeks)
- Terraform basics
- Resource management
- State management
- Modules and best practices

### 03-Advanced (8-12 weeks)
Expert-level skills for enterprise environments.

**01-Kubernetes-Advanced** (2-3 weeks)
- Helm charts
- StatefulSets
- RBAC and security
- Production patterns

**02-Service-Mesh-Istio** (2 weeks)
- Traffic management
- Security (mTLS)
- Observability
- Resilience patterns

**03-Monitoring-Logging** (2 weeks)
- Prometheus + Grafana
- ELK stack
- Alerting
- Distributed tracing

**04-DevSecOps** (2 weeks)
- Security scanning
- Secrets management
- Compliance
- Container security

**05-GitOps-ArgoCD** (1-2 weeks)
- GitOps principles
- ArgoCD workflows
- Progressive delivery
- Multi-environment management

## 🗓️ Recommended Learning Paths

### Path 1: Backend Developer to DevOps (4-6 months)
```
1. Linux + Git (2 weeks)
2. Docker + CI/CD (3 weeks)
3. Shell Scripting (1 week)
4. Kubernetes (3 weeks)
5. Cloud + IaC (4 weeks)
6. Advanced topics (4-8 weeks)
```
**Result**: Deploy and manage production applications

### Path 2: Frontend to Full-Stack DevOps (5-7 months)
```
1. Linux Fundamentals (1 week)
2. Git (1 week)
3. Docker Basics (2 weeks)
4. CI/CD with GitHub Actions (2 weeks)
5. Docker Compose (1 week)
6. Kubernetes Basics (2 weeks)
7. Cloud Platforms (2 weeks)
8. Choose specialization (4-8 weeks)
```
**Result**: Build and deploy full-stack applications

### Path 3: System Admin to DevOps Engineer (3-5 months)
```
1. Git + Docker (2 weeks)
2. CI/CD (2 weeks)
3. Kubernetes (3 weeks)
4. IaC with Terraform (2 weeks)
5. Advanced Kubernetes (3 weeks)
6. Monitoring + GitOps (3 weeks)
```
**Result**: Modern infrastructure management

## 💼 Career Paths

### DevOps Engineer
**Stack**: Docker, Kubernetes, CI/CD, Cloud, IaC
**Skills**: Automation, orchestration, monitoring
**Salary**: $90k - $150k+

### Site Reliability Engineer (SRE)
**Stack**: K8s, monitoring, incident response
**Skills**: System design, reliability, performance
**Salary**: $100k - $180k+

### Platform Engineer
**Stack**: Kubernetes, service mesh, developer tools
**Skills**: Internal platforms, developer experience
**Salary**: $110k - $170k+

### Cloud Architect
**Stack**: AWS/Azure/GCP, IaC, security
**Skills**: Architecture, cost optimization
**Salary**: $120k - $200k+

## 🚀 Getting Started

### Step 1: Prepare Your Environment
1. Install Linux (or use WSL on Windows)
2. Install Docker Desktop
3. Install Git
4. Choose a code editor (VS Code recommended)

### Step 2: Start Learning
1. Begin with **01-Basics/01-Linux-Fundamentals**
2. Complete all tasks in each section
3. Build projects to practice
4. Move to next topic only after mastering current one

### Step 3: Track Progress
- Use the checklist in each README
- Build a portfolio of projects
- Document your learnings
- Share on GitHub

## 📌 Important Notes

- **Don't rush** - DevOps is vast, take your time
- **Understand, don't memorize** - Focus on concepts
- **Practice on real projects** - Theory isn't enough
- **Learn to troubleshoot** - Essential DevOps skill
- **Security first** - Always consider security implications
- **Cost awareness** - Cloud resources cost money
- **Documentation** - Document everything you do
