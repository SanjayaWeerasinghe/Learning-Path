# Structural Design Patterns

Welcome to Structural Patterns! These patterns deal with object composition and relationships.

## Overview

Structural patterns explain how to assemble objects and classes into larger structures while keeping these structures flexible and efficient.

## Topics Covered

1. **Adapter** - Make incompatible interfaces work together
2. **Decorator** - Add behavior to objects dynamically
3. **Facade** - Provide simplified interface to complex subsystems

## Pattern Purposes

- **Adapter**: Legacy code integration, third-party library wrappers
- **Decorator**: Adding features without modifying original code
- **Facade**: Simplifying complex APIs, creating unified interfaces

## Learning Objectives

- Understand structural relationships between classes
- Implement composition over inheritance
- Simplify complex systems with facades
- Extend functionality with decorators
- Integrate incompatible interfaces with adapters

## Prerequisites

- Creational patterns completed
- Understanding of composition and inheritance
- Real-world coding experience
