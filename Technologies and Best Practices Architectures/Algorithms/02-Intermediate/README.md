# Algorithms Intermediate

Welcome to Intermediate Algorithms! This section covers essential data structures and recursive problem-solving.

## Overview

Build on your foundational knowledge with more complex data structures and algorithms commonly used in real-world applications and technical interviews.

## Topics Covered

1. **Recursion** - Recursive thinking and problem-solving
2. **Stack & Queue** - LIFO and FIFO data structures
3. **Linked Lists** - Dynamic data structures and pointer manipulation

## Learning Objectives

- Master recursive problem-solving
- Implement and use stacks and queues
- Understand linked list operations
- Analyze algorithm efficiency
- Solve medium-complexity problems

## Prerequisites

- Algorithms Basics completed
- Strong understanding of Big-O notation
- Comfortable with loops and conditionals
