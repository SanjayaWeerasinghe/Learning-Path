# Microservices Intermediate

Welcome to Intermediate Microservices! This section covers essential communication patterns and infrastructure.

## Overview

Learn how microservices communicate with each other and the infrastructure components that enable scalable microservices architectures.

## Topics Covered

1. **Service Communication** - Synchronous and asynchronous communication
2. **API Gateway** - Single entry point for clients
3. **Service Discovery** - Finding service instances dynamically

## Learning Objectives

- Implement service-to-service communication
- Set up and configure API gateways
- Use service discovery patterns
- Handle distributed transactions
- Implement circuit breakers and retry logic

## Prerequisites

- Microservices Basics completed
- REST API development experience
- Understanding of networking concepts

## Technologies

- API Gateways: Kong, NGINX, AWS API Gateway
- Service Discovery: Consul, Eureka, Kubernetes
- Communication: REST, gRPC, message brokers
