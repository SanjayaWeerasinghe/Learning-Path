# React Native Basics

Welcome to React Native Basics! This section covers fundamental concepts for building mobile applications.

## Overview

Learn the core components and concepts needed to start building React Native applications for iOS and Android.

## Topics Covered

1. **Setup & Hello World** - Environment setup and first app
2. **Core Components** - View, Text, Image, Button
3. **Styling & Layout** - StyleSheet and Flexbox
4. **Lists & ScrollViews** - FlatList, ScrollView, SectionList
5. **Forms & Input** - TextInput, handling user input
6. **Navigation Basics** - React Navigation fundamentals
7. **Touchables & Events** - Touch handling and gestures

## Learning Objectives

- Set up React Native development environment
- Use core React Native components
- Style applications with StyleSheet and Flexbox
- Create scrollable lists with FlatList
- Handle user input with forms
- Navigate between screens
- Respond to touch events

## Prerequisites

- JavaScript Intermediate completed
- React Basics completed
- Node.js installed

## Next Steps

After completing basics, proceed to **02-Intermediate** for state management, API integration, and animations.

Happy Learning!
