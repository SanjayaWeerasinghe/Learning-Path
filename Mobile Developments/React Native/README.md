# React Native - Build Cross-Platform Mobile Apps

## Overview

React Native is a framework for building native mobile applications using React and JavaScript. Write once, deploy to both iOS and Android platforms with native performance.

**Duration**: 6-8 weeks
**Prerequisites**: JavaScript (Intermediate) + React (Basics & Intermediate)

## Why Learn React Native?

- **Cross-Platform Development**: One codebase for iOS and Android
- **Leverage React Skills**: Use your existing React knowledge
- **Native Performance**: True native apps, not web wrappers
- **Hot Reload**: See changes instantly during development
- **Industry Adoption**: Used by Facebook, Instagram, Airbnb, Discord, Tesla
- **High Demand**: Mobile developers are in constant demand
- **Cost Effective**: Build for both platforms with one team

## Development Setup

### Option 1: Expo (Recommended for Beginners)
```bash
npm install -g expo-cli
expo init MyApp
cd MyApp
expo start
```

### Option 2: React Native CLI
```bash
npx react-native init MyApp
cd MyApp
npx react-native run-android
npx react-native run-ios
```

### Required Tools
- Node.js (v14+)
- VS Code with React Native extensions
- Android Studio (for Android)
- Xcode (for iOS - macOS only)
- Physical device or emulator
