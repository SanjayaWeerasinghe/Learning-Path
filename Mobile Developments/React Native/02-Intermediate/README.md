# React Native Intermediate

Welcome to React Native Intermediate! This section covers state management, APIs, and advanced features.

## Overview

Build on your basics knowledge with state management, API integration, local storage, advanced navigation, animations, and device features.

## Topics Covered

1. **State & Context** - Managing global state with Context API
2. **API Integration** - Fetching data from REST APIs
3. **AsyncStorage** - Local data persistence
4. **Advanced Navigation** - Nested navigators, deep linking
5. **Animations** - Animated API and transitions
6. **Images & Camera** - Image handling and camera access
7. **Maps & Location** - React Native Maps and geolocation
8. **Forms & Validation** - Complex forms with Formik and Yup

## Learning Objectives

- Manage application state effectively
- Integrate with external APIs
- Persist data locally
- Implement complex navigation patterns
- Create smooth animations
- Access device camera and gallery
- Work with maps and location services
- Build validated forms

## Prerequisites

- React Native Basics completed
- React hooks understanding
- REST API concepts
