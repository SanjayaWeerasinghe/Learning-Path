# .NET Intermediate

Welcome to the .NET Intermediate section! This section focuses on ASP.NET Core web development and building web applications.

## Overview

Learn to build modern web applications with ASP.NET Core, including MVC applications, Razor Pages, APIs, and understanding core web development concepts.

## Topics Covered

1. **ASP.NET Core MVC** - Model-View-Controller pattern in web apps
2. **Razor Pages** - Page-based development model
3. **Dependency Injection** - Built-in DI container in ASP.NET Core
4. **Configuration** - Managing app settings and environment config
5. **Middleware** - Request/response pipeline customization

## Learning Objectives

- Build web applications with ASP.NET Core MVC
- Create page-based apps with Razor Pages
- Implement dependency injection in web apps
- Manage configuration across environments
- Create custom middleware components

## Prerequisites

- Completion of .NET Basics
- Understanding of C# intermediate concepts
- Familiarity with HTTP and web concepts
