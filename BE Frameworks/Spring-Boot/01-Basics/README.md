# Spring Boot Basics

Welcome to Spring Boot Basics! This section covers the fundamentals of building applications with Spring Boot.

## Overview

Spring Boot is a Java framework that simplifies building production-ready applications with minimal configuration. It's widely used for enterprise Java development.

## Topics Covered

1. **Setup** - Installing Java, Maven/Gradle, and Spring Boot
2. **Project Structure** - Understanding Spring Boot project organization
3. **Annotations** - Core Spring Boot annotations

## Learning Objectives

- Set up Spring Boot development environment
- Create and run Spring Boot applications
- Understand project structure and configuration
- Use dependency injection
- Master essential annotations (@SpringBootApplication, @RestController, @Autowired)

## Prerequisites

- Java Intermediate knowledge
- Understanding of OOP concepts
- Maven or Gradle basics
