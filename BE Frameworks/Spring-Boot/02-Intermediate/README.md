# Spring Boot Intermediate

Welcome to Intermediate Spring Boot! This section covers building REST APIs and database integration.

## Overview

Learn to build production-ready REST APIs with database connectivity using Spring Data JPA and proper validation.

## Topics Covered

1. **REST API** - Building RESTful web services
2. **Spring Data JPA** - Database access with JPA
3. **Database Integration** - Connecting to MySQL, PostgreSQL
4. **Validation** - Input validation with Bean Validation
5. **Exception Handling** - Global exception handling

## Learning Objectives

- Create REST APIs with proper HTTP methods
- Use Spring Data JPA for database operations
- Implement validation for DTOs
- Handle exceptions globally
- Connect to relational databases
- Use repository pattern

## Prerequisites

- Spring Boot Basics completed
- SQL knowledge
- Understanding of REST principles

## Technologies

- Spring Web
- Spring Data JPA
- Hibernate
- MySQL/PostgreSQL
- Bean Validation
