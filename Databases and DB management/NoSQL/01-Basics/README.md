# NoSQL Basics

Welcome to NoSQL Basics! This section introduces non-relational databases and their use cases.

## Overview

NoSQL databases provide flexible schemas and horizontal scalability, making them ideal for modern web applications, big data, and real-time systems.

## Topics Covered

1. **Introduction** - What is NoSQL and when to use it
2. **MongoDB Basics** - Document-oriented database fundamentals
3. **Redis Basics** - Key-value store and caching

## Learning Objectives

- Understand NoSQL vs SQL differences
- Perform CRUD operations in MongoDB
- Use Redis for caching and session storage
- Choose the right NoSQL database type
- Design document schemas

## Prerequisites

- SQL basics understanding
- Backend development experience
- Basic command-line skills

## Database Types

- **Document**: MongoDB, CouchDB
- **Key-Value**: Redis, DynamoDB
- **Column-Family**: Cassandra, HBase
- **Graph**: Neo4j, ArangoDB
