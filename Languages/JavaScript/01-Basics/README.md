# JavaScript Basics

## Overview

Welcome to the JavaScript Basics section! This level covers the fundamental concepts you need to start programming in JavaScript. These are the building blocks that every JavaScript developer must master.

## Topics Covered

### 1. Variables
- Understanding `var`, `let`, and `const`
- Variable scope (global, function, block)
- Hoisting behavior
- Best practices for variable declaration

### 2. Data Types
- Primitive types: String, Number, Boolean, Undefined, Null, Symbol, BigInt
- Reference types: Objects, Arrays, Functions
- Type checking with `typeof`
- Type conversion and coercion

### 3. Operators
- Arithmetic operators (+, -, *, /, %, **)
- Comparison operators (==, ===, !=, !==, <, >, <=, >=)
- Logical operators (&&, ||, !)
- Assignment operators
- Ternary operator

### 4. Conditionals
- if/else statements
- else if chains
- switch statements
- Ternary operator for simple conditions

### 5. Loops
- for loop
- while loop
- do-while loop
- for...of loop (iterating over arrays)
- for...in loop (iterating over object properties)
- break and continue statements

### 6. Functions
- Function declarations
- Function expressions
- Arrow functions
- Parameters and arguments
- Return values
- Function scope

## Learning Path

1. Start with **Variables** to understand how to store and manage data
2. Learn **Data Types** to know what kinds of values you can work with
3. Master **Operators** to perform operations on data
4. Study **Conditionals** to make decisions in your code
5. Practice **Loops** to repeat actions efficiently
6. Understand **Functions** to organize and reuse code

## Prerequisites

- Basic understanding of programming concepts
- A code editor (VS Code, Sublime Text, etc.)
- A modern web browser with Developer Tools
- Node.js installed (optional but recommended)
