# JavaScript Intermediate

## Overview

Welcome to the Intermediate JavaScript section! This level builds upon the basics and introduces you to more powerful features of JavaScript, including modern ES6+ syntax and essential data manipulation techniques.

## Topics Covered

### 1. Arrays
- Array creation and initialization
- Accessing and modifying array elements
- Multi-dimensional arrays
- Array length and manipulation

### 2. Objects
- Object literals
- Properties and methods
- Accessing object properties (dot vs bracket notation)
- Object manipulation
- this keyword

### 3. Array Methods
- Iteration methods: `forEach()`, `map()`, `filter()`, `reduce()`
- Search methods: `find()`, `findIndex()`, `includes()`
- Modification methods: `push()`, `pop()`, `shift()`, `unshift()`, `splice()`, `slice()`
- Other useful methods: `sort()`, `reverse()`, `join()`, `concat()`

### 4. String Methods
- String manipulation: `slice()`, `substring()`, `substr()`
- Case conversion: `toLowerCase()`, `toUpperCase()`
- Search methods: `indexOf()`, `includes()`, `startsWith()`, `endsWith()`
- Transformation: `split()`, `replace()`, `trim()`, `padStart()`, `padEnd()`

### 5. Arrow Functions
- Arrow function syntax
- Implicit vs explicit return
- Lexical `this` binding
- When to use arrow functions vs regular functions

### 6. Destructuring
- Array destructuring
- Object destructuring
- Default values
- Nested destructuring
- Function parameter destructuring

### 7. Spread and Rest Operators
- Spread operator (...) for arrays and objects
- Rest parameters in functions
- Combining arrays and objects
- Cloning arrays and objects

### 8. Template Literals
- String interpolation with ${}
- Multi-line strings
- Expression evaluation
- Tagged templates

### 9. Modules
- ES6 module syntax
- Exporting (named exports, default exports)
- Importing modules
- Module patterns and organization

### 10. Error Handling
- try/catch/finally blocks
- Throwing errors
- Error types
- Creating custom errors
- Best practices for error handling

## Learning Path

1. Master **Arrays** and **Objects** - the fundamental data structures
2. Learn **Array Methods** and **String Methods** for data manipulation
3. Understand **Arrow Functions** for cleaner syntax
4. Practice **Destructuring** and **Spread/Rest** for elegant code
5. Use **Template Literals** for better string formatting
6. Organize code with **Modules**
7. Handle errors gracefully with **Error Handling**

## Prerequisites

Before starting this section, you should be comfortable with:
- Variables (var, let, const)
- Data types
- Operators
- Conditionals
- Loops
- Basic functions

## What You'll Build

By the end of this section, you'll be able to:
- Manipulate complex data structures
- Write cleaner, more concise code using ES6+ features
- Transform and filter data efficiently
- Organize code into reusable modules
- Handle errors professionally

## Next Steps

After completing the Intermediate section, you'll be ready for:
- **Advanced JavaScript**: Closures, Promises, Async/Await, Event Loop, and more
