# TypeScript Learning Path - Beginner to Advanced

TypeScript is a typed superset of JavaScript that compiles to plain JavaScript. Learn type safety and advanced features!

## 📚 Prerequisites
- Complete JavaScript basics first
- Understand JavaScript fundamentals
- Node.js installed

## 🎯 Course Structure

### 01-Basics
1. **Setup** - Installing TypeScript, tsconfig.json
2. **Type Annotations** - Basic types (string, number, boolean)
3. **Interfaces** - Object type definitions
4. **Classes** - OOP with types
5. **Functions** - Typing functions, parameters, returns

### 02-Intermediate
1. **Generics** - Reusable type-safe code
2. **Enums** - Named constants
3. **Type Aliases** - Custom type definitions
4. **Union Types** - Multiple possible types
5. **Modules** - Import/export with types

### 03-Advanced
1. **Advanced Types** - Intersection, mapped types
2. **Decorators** - Metadata and annotations
3. **Utility Types** - Partial, Pick, Omit, etc.
4. **Type Guards** - Runtime type checking
5. **Conditional Types** - Dynamic type creation

## ✅ Why TypeScript?
- ✅ Catch errors at compile time, not runtime
- ✅ Better IDE autocomplete and IntelliSense
- ✅ Easier refactoring
- ✅ Self-documenting code
- ✅ Used by React, Angular, Vue

## 🚀 Quick Start
```bash
# Install TypeScript
npm install -g typescript

# Check version
tsc --version

# Compile TypeScript
tsc file.ts

# Watch mode
tsc --watch
```
