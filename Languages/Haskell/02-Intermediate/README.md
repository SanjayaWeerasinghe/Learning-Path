# Haskell Intermediate

## Overview

This section covers core Haskell concepts that are essential for practical programming. You'll learn about custom types, type classes, and the famous monads.

## Topics Covered

1. **Custom Types** - Creating your own data types with `data`, `type`, and `newtype`
2. **Type Classes** - Defining and implementing type classes
3. **Functors** - The Functor type class and fmap
4. **Applicative Functors** - Applying functions in a context
5. **Monads** - Understanding the Monad type class
6. **Monads in Practice** - IO, Maybe, Either, and more
7. **Modules** - Organizing and structuring code
8. **Input/Output** - Reading files, writing files, handling I/O
9. **Errors & Exceptions** - Error handling strategies
10. **Testing** - QuickCheck and HUnit testing frameworks

## Learning Path

Complete these topics in order, especially Functors → Applicative → Monads which build on each other.

## Time Commitment

Expect to spend 4-6 weeks on this section if studying 1-2 hours daily.

## Prerequisites

- Completed all Basics topics
- Comfortable with recursion and higher-order functions
- Understanding of type signatures

## After Completing Intermediate

You will be able to:
- Create and use custom data types
- Understand and use Functors, Applicative, and Monads
- Handle errors properly in Haskell
- Organize code into modules
- Write and test real applications
- Read most Haskell code in the wild

## Next Steps

After completing all Intermediate topics, move on to `03-Advanced` to learn about monad transformers, lenses, parsing, and more.
