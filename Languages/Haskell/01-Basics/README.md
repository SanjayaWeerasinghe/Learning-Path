# Haskell Basics

## Overview

This section covers the fundamental concepts of Haskell and functional programming. These are the building blocks you need before moving to more advanced topics.

## Topics Covered

1. **Hello World & Setup** - Installing Haskell and writing your first program
2. **Basic Syntax** - Functions, expressions, and basic operators
3. **Types & Type Classes** - Understanding Haskell's type system
4. **Lists** - The fundamental data structure
5. **Tuples** - Working with fixed-size collections
6. **Pattern Matching** - Deconstructing data elegantly
7. **Guards & Where** - Conditional expressions and local bindings
8. **Recursion** - The functional way to loop
9. **Higher-Order Functions** - Functions that work with functions
10. **List Comprehensions** - Elegant list generation

## Learning Path

Complete these topics in order. Each builds on the previous ones.

## Time Commitment

Expect to spend 3-4 weeks on this section if studying 1-2 hours daily.

## Prerequisites

- Basic programming knowledge (any language)
- Willingness to think differently about programming
- Patience with functional paradigm

## After Completing Basics

You will be able to:
- Write simple Haskell programs
- Understand type signatures
- Work with lists and recursion
- Use higher-order functions like map, filter, fold
- Read basic Haskell code

## Next Steps

After completing all Basics topics, move on to `02-Intermediate` to learn about custom types, type classes, and monads.
