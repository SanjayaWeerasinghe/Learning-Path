# C# Basics

Welcome to the C# Basics section! This section covers fundamental concepts of C# programming language.

## Overview

C# is a modern, object-oriented programming language developed by Microsoft. It's widely used for building Windows applications, web applications, games (Unity), and enterprise software.

## Topics Covered

1. **Hello World** - Your first C# program
2. **Variables & Data Types** - Understanding data storage and types
3. **Operators** - Arithmetic, logical, and comparison operators
4. **Conditionals** - Decision-making with if/else statements
5. **Loops** - Iterating with for, while, and foreach loops

## Learning Path

Complete the topics in order:
- Start with Hello World to understand basic program structure
- Learn about variables and data types for data management
- Master operators for performing operations
- Understand conditionals for decision-making logic
- Practice loops for repetitive tasks

## Prerequisites

- .NET SDK installed
- Visual Studio or Visual Studio Code
- Basic understanding of programming concepts

## Learning Objectives

By completing this section, you will:
- Understand C# syntax and structure
- Work with different data types
- Implement control flow in programs
- Write basic C# programs independently
- Build a foundation for intermediate concepts
