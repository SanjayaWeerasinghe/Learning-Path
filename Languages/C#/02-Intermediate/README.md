# C# Intermediate

Welcome to the C# Intermediate section! This section focuses on Object-Oriented Programming principles and intermediate C# concepts.

## Overview

This section builds upon basic C# knowledge and introduces you to the power of Object-Oriented Programming (OOP) in C#. You'll learn to design and build more complex, maintainable applications.

## Topics Covered

1. **Arrays** - Working with collections of elements
2. **Lists** - Dynamic collections and List<T>
3. **Methods** - Creating reusable code blocks
4. **Classes & Objects** - Core OOP concepts
5. **Constructors** - Object initialization
6. **Properties** - Encapsulation and data access
7. **Inheritance** - Code reusability through inheritance
8. **Polymorphism** - Method overriding and virtual methods
9. **Interfaces** - Contracts and abstraction
10. **Exception Handling** - Robust error management

## Learning Path

Follow the topics sequentially:
- Master arrays and lists for data management
- Learn methods to organize code
- Understand classes and objects as building blocks
- Apply OOP principles (Inheritance, Polymorphism, Encapsulation)
- Implement interfaces for abstraction
- Handle errors gracefully with exception handling

## Prerequisites

- Completion of C# Basics section
- Understanding of variables, data types, and control flow
- Familiarity with basic C# syntax

## Learning Objectives

By completing this section, you will:
- Design programs using OOP principles
- Create and use custom classes and objects
- Implement inheritance hierarchies
- Apply polymorphism for flexible code
- Work with interfaces for abstraction
- Handle exceptions effectively
- Build more complex, maintainable applications
