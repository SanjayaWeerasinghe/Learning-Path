# Angular Intermediate

Welcome to Angular Intermediate! This section covers essential Angular features for building real-world applications.

## Overview

Learn services, dependency injection, routing, forms, HTTP communication, and reactive programming with RxJS.

## Topics Covered

1. **Services & Dependency Injection** - Creating services, DI pattern
2. **Routing** - Navigation, route parameters, child routes
3. **Forms** - Template-driven and Reactive forms
4. **HTTP Client** - API integration, interceptors
5. **RxJS & Observables** - Async data streams, operators

## Learning Objectives

- Create and inject services
- Implement routing and navigation
- Build complex forms with validation
- Communicate with backend APIs
- Master RxJS for reactive programming
- Handle async operations effectively

## Prerequisites

- Angular Basics completed
- Understanding of REST APIs
- TypeScript Intermediate knowledge

Keep Building!
