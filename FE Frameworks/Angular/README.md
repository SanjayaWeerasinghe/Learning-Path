# Angular - Enterprise Web Applications

## Overview

Angular is a platform and framework for building single-page client applications using HTML, CSS, and TypeScript. Developed and maintained by Google, it's a complete rewrite of AngularJS.

**Duration**: 8-10 weeks
**Prerequisites**: JavaScript (Intermediate) + TypeScript (Basics & Intermediate)

## Why Learn Angular?

- **Complete Framework**: Batteries-included with routing, forms, HTTP client
- **TypeScript First**: Built with TypeScript for type safety
- **Enterprise Ready**: Used by Fortune 500 companies
- **Component-Based**: Modular, reusable architecture
- **Two-Way Binding**: Efficient data synchronization
- **Dependency Injection**: Powerful DI system
- **CLI Tool**: Powerful Angular CLI for scaffolding and building

## Development Setup

### Prerequisites
- Node.js (v16+)
- npm or yarn
- TypeScript knowledge

### Install Angular CLI

```bash
npm install -g @angular/cli

# Check installation
ng version

# Create new project
ng new my-app

# Run development server
cd my-app
ng serve

# Open browser to http://localhost:4200
```

## Comparison: Angular vs React

| Feature | Angular | React |
|---------|---------|-------|
| **Type** | Framework | Library |
| **Language** | TypeScript (required) | JavaScript/TypeScript (optional) |
| **Learning Curve** | Steeper | Gentler |
| **Architecture** | Complete (routing, forms, HTTP) | Minimal (need third-party) |
| **Data Binding** | Two-way | One-way |
| **DOM** | Real DOM | Virtual DOM |
| **CLI** | Angular CLI | Create React App |
