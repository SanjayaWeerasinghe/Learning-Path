# Angular Basics

Welcome to Angular Basics! This section covers fundamental concepts of Angular framework.

## Overview

Learn the core building blocks of Angular applications: components, templates, data binding, directives, and pipes.

## Topics Covered

1. **Setup & Hello World** - Angular CLI, project structure, first component
2. **Components** - Component architecture, lifecycle hooks
3. **Templates & Data Binding** - Interpolation, property/event binding
4. **Directives** - Structural and attribute directives
5. **Pipes** - Data transformation in templates

## Learning Objectives

- Set up Angular development environment
- Create and use components
- Understand data binding techniques
- Use built-in directives
- Transform data with pipes
- Build basic Angular applications

## Prerequisites

- JavaScript Intermediate completed
- TypeScript Basics completed
- Node.js installed
- Basic understanding of HTML/CSS
